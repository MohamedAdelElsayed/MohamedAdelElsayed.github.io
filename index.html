00

Project overview

An end-to-end GIS workflow for a residential compound: digitization, geometry quality control, attribute engineering, spatial analysis, and 3D visualization, built in Esri ArcGIS (ArcMap + ArcScene).

01

Spatial data digitization

340 building footprints, the road network, 23 green/garden areas, and the study boundary were digitized and projected to WGS 1984 UTM Zone 36N, organized inside a Personal Geodatabase.

02

Geometry quality control

Before any analysis, the building layer was checked with Check Geometry. It flagged one self-intersection error (out of 340 buildings) — repaired, then re-verified at zero remaining issues. Clean geometry first; analysis only after.

Check Geometry — 1 issue found
After Repair Geometry — 0 issues
03

Attribute engineering

A standardized Building_ID scheme (B001–B340) was generated programmatically via Python in the ArcGIS Field Calculator, not entered by hand. A Height field, derived from each building's real footprint area, followed the same approach.

05

Data-driven 3D visualization

Building footprints were extruded in ArcScene using the attribute-based Height field — not a fixed constant — so the model's height responds directly to real feature data. This is the difference between a 3D model and a data-driven 3D visualization.
